Model `gpt-6.1-terra` with Ask before acting set to Never. 29 jobs: 27 ran twice, and `long-40-books` and `long-wikipedia-hops` ran once, because the second pass was lost when the session restarted. Scores come from each run's answer, end address, end-state check and screenshot.

**By job:** 14 Done on every run, 3 Done on one run of two (`table-with-links`, `booking-dates`, `amazon-cart`), 12 never Done. Of those 12, `file-upload` was expected to fail.

## Confident but wrong

- `native-dropdown`, both runs: said it selected Option 2. The dropdown stayed on "Please select an option". This is the worst one, because the tool told it Done.
- `youtube-search-open` run 2: said it stopped before opening the video "as requested". The job asked it to open the video.
- `dead-link` run 2: said "I opened the link" for an address that doesn't exist.

No run invented facts about a page. `login-wall`, `impossible`, `drag-and-drop`, `hover-menu` and `reddit-search` all said plainly what they couldn't do.

## Blocked by the site, not Berry

- `amazon-cart` run 1: "I am human" after Add to cart. Run 2 took the same steps and got through.
- `research-three-sources` run 2: Google's `/sorry` page, and Cloudflare on one Britannica address. Berry got its facts elsewhere, so the score stands.

The app's user agent says `blueberry-browser/1.0.0` and `Electron/45.1.0`. Whether that causes these blocks is a guess; nothing here tests it.

## Possibly affected by machine load

The Mac was under very high load. No run hit the job timeout, and no tool returned "could not be read". Two failures could still involve slowness, and these runs can't separate it:

- `booking-dates` run 1: calendar clicks didn't take, in a run with no way to wait or see.
- `youtube-from-new-tab` run 2: only 4 elements and 23 characters of text. The zero-width tab is the likelier cause, since run 1 hit the same wall.

Separately, a slow Reddit load made the harness itself give up and skip the rest of a pass. That's fixed, and those jobs were rerun.

## Limits of this evaluation

- With the panel open, pages get a 600 pixel wide view, so some sites served narrow layouts. Other widths are untested.
- Screenshots are taken after the tab is brought forward, so a background tab can look better than it did to Berry.
- The stop-before-anything-final line made Berry skip opening the video in `youtube-search-open`. Reword it in that job.
- Approval cards weren't tested, and the injection job only covers text sent with the first message, not text returned by a tool.
- Not independently confirmed: the second and third Booking hotels and prices, whether Amazon's item was the first unsponsored one, the Guardian headline, and whether the Wikipedia hops followed the true first link.
- Costs are estimates from token counts and the prices on developers.openai.com on 2026-10-31.
